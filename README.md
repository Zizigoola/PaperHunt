# 📚 Paper Hunt

**Paper Hunt** is a semantic search engine to discover relevant research papers in Machine Learning, Deep Learning, and AI.  
It uses Sentence-BERT embeddings and vector similarity search (FAISS) to retrieve papers based on meaning.

## Features
- Semantic search over research paper abstracts
- Custom queries like "transformers for vision" or "GANs for medical imaging"
- Fast vector similarity retrieval using FAISS
- Easily extendable with new papers or sources
